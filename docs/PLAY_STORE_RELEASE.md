# Google Play 출시 준비

## 앱 기본 정보

- 앱 이름: 모두의 화장실
- 패키지 ID: `com.sharetoilet.app`
- 초기 버전: `1.0` (`versionCode 1`)
- 카테고리 제안: 여행 및 지역정보
- 가격: 무료
- 광고: 있음 (Google AdMob 하단 배너 1개)
- 로그인: 없음

## 스토어 문안

### 짧은 설명 (80자 이내)

전국 공중화장실을 지도와 거리순으로 찾고 편의·운영 정보를 확인하세요.

### 자세한 설명

모두의 화장실은 현재 위치나 검색어를 기준으로 가까운 공중화장실을 빠르게 찾을 수 있는 지도 앱입니다.

주요 기능

- 전국 공중화장실 위치를 지도와 목록으로 확인
- 현재 위치 기준 가까운 화장실 탐색
- 주소 검색 및 거리순 정렬
- 운영시간과 편의시설 정보 확인
- 사용자가 확인한 화장실 상태를 기기에 기록
- 차박 관련 확인 상태와 안내 표시
- 네이버 지도 길찾기 연결

위치 권한은 ‘내 주변’ 기능을 사용할 때만 요청하며 선택 사항입니다. 공공데이터와 현장 정보는 변경될 수 있으므로 실제 이용 전 관리기관 및 현장 안내를 확인해 주세요.

## Play Console 설문 초안

- 앱 액세스: 모든 기능을 로그인 없이 이용 가능
- 광고: 광고 포함
- 타겟 연령층: 일반 사용자(아동 전용 앱 아님)
- 뉴스 앱: 해당 없음
- 정부 앱: 해당 없음
- 금융 기능: 해당 없음
- 건강 기능: 해당 없음

### 데이터 안전성

- 정확한 위치: 앱 기능을 위해 사용, 선택 사항
- 운영자 서버로 위치를 수집하거나 저장하지 않음
- 사용자 계정 및 회원정보 수집 없음
- 위치는 주변 화장실 검색을 위해 기기에서 처리
- 지도 제공 과정의 제3자 처리는 네이버 정책 적용
- Google Mobile Ads SDK가 광고 제공·측정·부정 사용 방지를 위해 광고 식별자 등 기기 식별자, 앱 상호작용 및 진단 정보를 처리할 수 있음
- Play Console 데이터 안전성 답변은 Google Mobile Ads SDK 데이터 공개 안내와 실제 AdMob 설정을 기준으로 제출
- 전송되는 네트워크 데이터는 HTTPS 사용
- 데이터 삭제 요청: 서버 저장 데이터가 없으며 로컬 기록은 앱 데이터 삭제로 제거 가능

> Play Console의 질문 문구에 따라 “수집” 정의가 달라질 수 있으므로 제출 화면에서 네이버 지도 SDK/웹 API의 처리 범위를 최종 확인한다.

## 필수 그래픽

- 앱 아이콘: `assets/icon.png` (1024×1024, 준비됨)
- 기능 그래픽: 1024×500 PNG/JPG 필요
- 휴대전화 스크린샷: 최소 2장, 권장 4~8장
  1. 현재 위치 주변 지도
  2. 화장실 목록과 거리 표시
  3. 상세 정보와 길찾기
  4. 차박 상태 필터

## 빌드 명령

```bash
npm run android:aab
```

결과 파일:

`android/app/build/outputs/bundle/release/app-release.aab`

서명 설정이 없으면 빌드 검증용 AAB가 만들어질 수 있지만 Play 업로드 전에는 반드시 업로드 키로 서명해야 한다.
