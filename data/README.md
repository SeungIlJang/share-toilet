# data/ — 원본 데이터 넣는 곳

여기에 **전국 공중화장실 표준데이터 CSV** 를 넣으면 됩니다.

## 1. CSV 받기
공공데이터포털에서 다운로드:
- https://www.data.go.kr → "전국공중화장실표준데이터" 검색 → CSV 다운로드
- (행정안전부 · 전국공중화장실표준데이터)

## 2. 이 폴더에 복사
파일명은 아무거나 상관없습니다. 확장자만 `.csv` 이면 됩니다.

```
data/
└─ 전국공중화장실표준데이터.csv   ← 여기에 복사
```

> 여러 개의 `.csv` 가 있으면 **가장 최근에 수정된 파일** 하나를 사용합니다.

## 3. 병합 실행
프로젝트 루트에서:

```bash
npm run data:build
```

- CSV(서울 지역)를 파싱해 `src/assets/data.json` 을 **새로 생성**합니다.
- 개방시간 · 변기수 · 장애인 화장실 · 기저귀교환대 · 전화번호 등이 채워지며,
  앱 정보창에 자동으로 표시됩니다.
- 인코딩(EUC-KR/UTF-8)은 자동 감지합니다.

## 4. 앱에 반영
```bash
npm run android:run        # 또는 npm run dev (웹)
```

---

CSV 는 용량이 커서 git 에 커밋하지 않습니다(`.gitignore` 처리). 결과물인 `src/assets/data.json` 만 커밋됩니다.
